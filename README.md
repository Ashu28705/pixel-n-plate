# 🍽️ Pixel n Plate – Café + Game Zone Web Platform

Pixel n Plate is a **full-stack web application** designed for a modern café that combines **food, gaming, and events** under one roof.  
The project is built as part of a **Business Model Canvas (BMC) and Web Development project**, showcasing real-world features like event booking, feedback management, and database integration.

---

## 🚀 Project Overview

Pixel n Plate aims to create a digital presence for **Ahmedabad’s first Café + Game Zone + Event Space**, where users can:
- Explore food menus from multiple brands  
- Discover available games  
- View upcoming events  
- Book events online  
- Submit feedback and contact requests

## ✨ Implemented Features

- Responsive homepage with hero banner and navigation  
- Interactive multi-brand food menu (accordion-style)  
- Gaming zone showcase (VR, Bowling, Pool, Go-Karting, etc.)  
- Events listing with a single **Book Now** button  
- Event booking system with database storage  
- Feedback form with rating system  
- Contact form for user inquiries  
- PHP–MySQL connectivity using XAMPP  
- Online deployment with live database support  

---

## 🗃️ Database Structure

**Database Name:** `pixelnplate_db`

### Tables:
- `bookings` – Stores event booking details  
- `feedback` – Stores user feedback and ratings  
- `contacts` – Stores contact form messages  
- `menu_items` (optional) – For dynamic menu management  

To create the database and tables automatically, import `setup.sql` into phpMyAdmin or run it from your MySQL client.
